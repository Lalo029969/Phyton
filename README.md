# 🐍 Repositorio de Programas en Python

Este repositorio contiene scripts y programas desarrollados en **Python** con el objetivo de practicar y entender desde la sintaxis básica
hasta ejercicios más avanzados. Ideal para reforzar fundamentos y preparar el camino hacia proyectos más complejos.

## 📘 Algunos Temas Incluidos Son:

- ✅ Hola Mundo
- ✅ Asignación de valores
- ✅ Operadores aritméticos
- ✅ Operadores relacionales
- ✅ Operadores lógicos
- ✅ Entrada y salida de datos

## 🧠 Objetivo

Desarrollar habilidades sólidas en programación con Python mediante la práctica progresiva, clara y bien documentada.

## 🚀 Cómo usar

1. Clona el repositorio:

   git clone https://github.com/Lalo029969/Python.git

2. Navega entre los archivos y ejecuta los scripts con:

   python nombre_del_script.py
